# TitenFin 💰📱
> **Cermat • Amanah • Terdata**  
> *Aplikasi Pengelolaan Kredit Barang Fleksibel & Buku Rekening Kas Titipan Amanah*

---

## 🌟 Filosofi Nama
Diambil dari bahasa Jawa **"Titen"** (cermat, teliti, jeli, dan selalu ingat menandai hal-hal penting) dan **"Fin"** (Finance). TitenFin dirancang khusus untuk memecahkan problem perputaran kas mikro informal di mana akad kredit sangat fleksibel dan kas usaha sering bercampur dengan uang titipan orang lain.

---

## 🚀 Fitur Unggulan

### 1. 🛡️ Tiga Kotak Kas (Pemisahan Kas Amanah)
Mencegah jebakan "kas semu" di mana pemilik usaha merasa uangnya banyak padahal milik orang lain:
- **Kotak 1: Kas Sendiri (Modal & Laba Realisasi)** — Uang riil milik Anda yang aman untuk operasional atau dibelanjakan.
- **Kotak 2: Total Piutang di Luar** — Total pokok + margin yang masih dicicil oleh nasabah.
- **Kotak 3: Dana Titipan (Amanah)** — Uang orang lain yang dititipkan di Anda. Sistem menandainya sebagai dana amanah yang **tidak boleh terpakai belanja pribadi**.

### 2. 💸 Pembayaran Cicilan Fleksibel (Nyicil Cicilan / Parsial)
- Nasabah tidak diwajibkan bayar pas. Bebas membayar berapa pun nominal yang dibawa (parsial/eceran atau bayar dobel sekaligus).
- Sistem otomatis menghitung sisa tagihan secara presisi.

### 3. ✨ Pelunasan Dipercepat & Penyesuaian Diskon Profit
- Jika nasabah melunasi kredit lebih awal, tersedia kalkulator diskon margin keuntungan instan sesuai kesepakatan akhir.
- Status otomatis lunas dan bukti surat lunas siap dikirim via WhatsApp.

### 4. 🏦 Buku Kas Rekening Titipan Uang
- Tiap penitip memiliki catatan saldo berjalan (*running balance*) sendiri.
- Setor bertahap (+) & tarik sebagian (-).
- **Proteksi Saldo:** Penarikan tidak bisa melebihi saldo yang dititipkan.

### 5. 👁️ Mode Sensor Privasi (Privacy Blur)
- Tombol satu-klik untuk menyamarkan seluruh nominal angka saldo di layar ketika Anda sedang membuka aplikasi di depan orang lain / nasabah.

### 6. ☁️ Sinkronisasi Akun Email & Ekspor Cadangan
- Data terhubung dengan identitas email Anda.
- Mendukung ekspor cadangan offline (`.json`) dan pemulihan data instan.

## 💻 Cara Menjalankan Aplikasi

1. Buka terminal di folder proyek:
   ```bash
   npm run dev
   ```
2. Buka browser di:
   [http://localhost:3000](http://localhost:3000)

3. Untuk membuka di HP:
   - Hubungkan HP dan Laptop ke jaringan Wi-Fi yang sama.
   - Buka alamat IP laptop Anda di browser HP (contoh: `http://192.168.1.x:3000`).
   - Tekan menu browser lalu pilih **"Tambahkan ke Layar Utama" / "Install App"** untuk menggunakannya layaknya aplikasi HP asli (PWA).
